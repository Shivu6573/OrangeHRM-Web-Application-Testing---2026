# OrangeHRM Web Application – Manual Testing

## Project Overview
This project focuses on manual testing of the OrangeHRM demo web application to verify its functionality and identify potential defects.

## Application Under Test
- Application: OrangeHRM
- URL: https://opensource-demo.orangehrmlive.com/
- Testing Type: Manual Testing
- Database: PostgreSQL (SQL Practice)

## Modules Tested
- Login
- Employee (PIM)
- Admin

## Testing Activities
- Requirement Analysis
- Test Scenario Preparation
- Test Case Design
- Test Data Preparation
- Test Execution
- Defect Identification and Reporting
- Regression Testing
- SQL Validation

## Tools Used
- Microsoft Excel
- PostgreSQL
- SQL
- Git and GitHub

All testing documents, test cases, execution results, and supporting screenshots are maintained in this repository.
